Multi-omics reprogramming drives a reversal of disease susceptibility during ageing in Magallana gigas

Code repository

This repository contains the scripts and code used for the computational analyses presented in the manuscript:

“Multi-omics reprogramming drives a reversal of disease susceptibility during ageing in Magallana gigas”

Overview

The aim of this project was to investigate how ageing reshapes molecular responses and disease susceptibility in the Pacific oyster (Magallana gigas) using an integrative multi-omics approach, including transcriptomics, epigenomics, and metabolomics data.
This repository includes all scripts used for data processing, statistical analysis, visualization, and multi-omics integration.

Contents:
Transcriptomic data processing and differential expression analysis (RNA-seq)
Epigenomic analysis (EM-seq / DNA methylation)
Metabolomic data processing and normalization
Multi-omics integration workflows
Gene Ontology (GO) enrichment analyses
Network-based analyses and visualization 
Figure generation scripts

Requirements
Analyses were performed primarily in:
R (≥ 4.x)
Python (≥ 3.x)
Bioconductor packages for omics analyses
ggplot2 and related visualization libraries
Additional packages as specified in individual scripts
Data availability

Raw and processed data supporting the findings of this study are available in the corresponding public repositories (see manuscript for accession numbers).

Usage
Each folder contains scripts corresponding to specific analytical steps. Scripts should be executed in the order described in the manuscript methods section. Paths may need to be adapted to local computing environments.

Notes
This repository is intended to ensure transparency and reproducibility of the analyses performed in the study. For questions or issues, please contact the corresponding author.
